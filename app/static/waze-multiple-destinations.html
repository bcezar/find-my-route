Waze with Multiple Destinations Organized

Waze is excellent for avoiding traffic, but it does not support multiple destinations in a single route. Find My Route fills that gap: it calculates the ideal sequence and opens each stop individually in Waze with a single tap.

What Waze can't do (and Find My Route solves)

  • Waze does not accept multiple stops in a single route
  • There is no way to import an address list in Waze
  • There is no automatic sequence optimization
  • There is no tracking of which addresses have already been visited

With Find My Route, you organize everything before you leave and use Waze only for navigation — which is what it does best.

How to use Waze with Find My Route

1
Add your destinations in Find My Route — up to 5 stops on the free plan, or up to 50 on the Pro plan. One by one or by importing a CSV.
2
Calculate the optimized route — the order that minimizes total distance is calculated in seconds.
3
Activate Execution Mode — see one stop at a time with the full address, distance, and estimated time.
4
Tap "Open in Waze" — Waze opens directly with the current stop's address. After arriving, return to Find My Route and advance to the next stop.

Remember my favorite app

If you always prefer Waze, Find My Route has a "Remember my choice" option. After the first selection, the button will open Waze directly, without asking every time.

Why use Waze for deliveries?

  • Real-time traffic, speed camera, and accident alerts
  • Dynamic routing that recalculates throughout the delivery
  • Active community reporting road events
  • Free, just like Find My Route
